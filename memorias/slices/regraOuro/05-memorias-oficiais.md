# Regra 5. memorias/ é o repositório oficial - replica para o pessoal, nunca o contrário

Toda memória é escrita e atualizada primeiro em `E:\Projetos\lidar\memorias`; depois a pasta é espelhada
para a memória pessoal do agente. Nunca se copia do pessoal para o oficial. A pasta principal guarda SÓ os
índices (`MEMORY.md`, `regraOuro.md`, `Arquitetura.md`, `jobLog.md`); toda submemória vive em `slices/`
(`slices/regraOuro/`, `slices/projeto/`, `slices/referencia/`...). Estrutura: `regraOuro.md` +
`slices/regraOuro/`, `Arquitetura.md`, `jobLog.md`, e submemórias em `slices/` indexadas em `MEMORY.md`.
